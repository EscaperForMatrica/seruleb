# Для Мадины ❤️

Романтический интерактивный мини-сайт: путешествие из нежных карточек,
которое заканчивается признанием в любви.

Сделано на чистых **HTML + CSS + JavaScript** — без библиотек, фреймворков
и без шага сборки.

## Возможности

- Glassmorphism и liquid-glass эффекты, градиенты, свечения
- Звёздное небо и светящиеся частицы на canvas, северное сияние
- Кнопка «Нет», которую невозможно нажать (убегает от курсора и касаний)
- Цепочка романтичных карточек с плавными переходами
- Финал: печать текста по буквам, пульсирующее сердце, конфетти и сердечки
- Фоновая музыка и звуки через Web Audio API — без аудиофайлов
- Полная адаптивность под телефон и десктоп

## Структура

| Файл         | Назначение            |
|--------------|-----------------------|
| `index.html` | Разметка всех сцен    |
| `style.css`  | Стили и анимации      |
| `script.js`  | Логика, звук, эффекты |

Служебные файлы:

| Файл             | Назначение                                                        |
|------------------|-------------------------------------------------------------------|
| `wrangler.jsonc` | Конфиг Cloudflare: раздача статики, без сборки                    |
| `.assetsignore`  | Что не выкладывается на сайт (README, конфиги, служебные папки)   |
| `_headers`       | HTTP-заголовки: безопасность и запрет индексации                  |
| `robots.txt`     | Просьба к поисковикам не индексировать сайт                       |
| `.gitignore`     | Что не попадает в репозиторий (`.DS_Store`, `.env`, логи и т. д.) |

## Локальный запуск

Можно просто открыть `index.html` двойным кликом. Но лучше поднять локальный
сервер — так гарантированно подтянется шрифт Montserrat и поведение совпадёт
с продакшеном:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Сборка

Шага сборки нет. Репозиторий — это и есть готовый продакшен: Cloudflare
раздаёт файлы как есть.

Настройки проекта в панели Cloudflare (Workers → Builds):

| Поле              | Значение             |
|-------------------|----------------------|
| Build command     | *(оставить пустым)*  |
| Deploy command    | `npx wrangler deploy`|
| Production branch | `main`               |

Всё остальное задаётся в `wrangler.jsonc` и менять его в панели не нужно.

## Как публиковать изменения

Деплой полностью автоматический:

```bash
git add -A && git commit -m "Описание правки" && git push
```

Cloudflare увидит новый коммит в `main`, выложит новую версию за несколько
секунд и сам сбросит кэш. Нажимать что-либо в панели не нужно.

Пуш в любую другую ветку создаёт отдельный **preview-деплой** со своим URL —
удобно посмотреть правки, не трогая основной сайт:

```bash
git checkout -b proba
git push -u origin proba
```

## Приватность

Опубликованный сайт доступен по своему адресу **любому, кто знает или угадает
ссылку** — репозиторий приватный, а сам сайт нет. `_headers` и `robots.txt`
просят поисковики не индексировать страницы, но это просьба, а не защита.

## Стек

Ванильные HTML5, CSS3 и JavaScript (ES6+). Внешняя зависимость одна — шрифт
Montserrat с Google Fonts; при отсутствии интернета подставляется системный
шрифт. Все внутренние пути относительные.
